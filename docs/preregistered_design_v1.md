## 0. 논문의 핵심 질문 한 문장

> 실험으로 검증된 초파리 전체 뇌 모델(Shiu et al. 2024)에서, **행동 출력·신경 반응·강건성을 보존하면서 연결을 어디까지 제거할 수 있고, 그 한계는 무엇이 결정하는가** — 연결의 세기인가, 위치인가, 네트워크 상태인가, 과제인가?

"압축했더니 됐다"가 아니라 "**무엇이 압축 가능성을 결정하는가**"를 4개 축(세기·위치·상태·과제)으로 분해해서 답하는 논문. 이 프레임이면 결과가 어느 쪽이어도 발견이 된다.

## 2. 과제 (전부 Shiu 2024에서 실험 검증된 회로)

| 과제 | 자극 | 판독 | 지표 | 회로 성격 | 왜 필요한가 |
|---|---|---|---|---|---|
| **sugar** | 설탕 GRN 21개 @100 Hz | MN9 발화율 | 원본 대비 비율 | feedforward 흥분 | 기준 과제, 파일럿 연속 |
| **bitter** | 설탕 100 Hz + 쓴맛 GRN 21개 @100 Hz | MN9 | 억제 지수 SI = 1 − MN9(설탕+쓴맛)/MN9(설탕) | **억제 경로** | 약한 억제 연결이 압축에서 살아남는지. 파일럿 k=2에서 MN9가 1.05로 *올라간* 탈억제 현상의 검증 |
| **water** | 물 GRN 18개 @140 Hz | MN9 | 비율 | 설탕과 뉴런 ~250개 공유 | 두 과제가 같은 하위 그래프를 쓰는지 → 과제 간 전이 |
| **groom** | JON-CE 70개 @100 Hz / JON-F 60개 @100 Hz | aBN1 | 특이성 = aBN1(CE) − aBN1(F) | **시냅스 수는 비슷한데 기능이 다른 두 경로** | "세기가 아니라 위치"를 가장 직접적으로 시험. 압축이 CE/F 차이를 없애면 위치 정보가 소실된 것 |

train/held-out 분리: task-aware 방법(`act`)은 각 과제의 **첫 자극 조건**(sugar100, jonCE100)만 보고 점수를 만든다. 두 번째 조건(bitter, jonF)은 held-out.

## 3. 가설과 사전 예측 (결과별 해석을 미리 고정)

### H1. 절벽의 위치 — 세기 축
- 예측: magnitude pruning의 MN9 비율은 k ≤ 10까지 >0.8, k ≥ 31 어딘가에서 급락.
- 나오면: "기능 보존에 필요한 최소 연결 = 시냅스 ≥ k* 이상인 edge 집합". Schlegel의 정형성 임계(≥10 = 90% 재현, ≥31 = 99%)와 대응시켜 **"진화적으로 보존되는 연결 = 기능에 필요한 연결"** 주장.
- 안 나오면(k=50에서도 유지): 회로가 극소수의 초강력 연결로만 돌아간다는 것 → 뉴런 수준 압축(§8)으로 이동. 그것도 발견.

### H2. 네트워크 상태 축 — 논문의 생사
- 조작: 모든 뉴런에 백색 잡음 σ를 넣어 자발 발화 1~5 Hz 상태를 만든다 (§4.2).
- 예측 A (뒤집힘): 배경 활동이 있으면 약한 연결 수천 개의 합이 역치 근처 뉴런을 밀어, magnitude pruning의 절벽이 **훨씬 앞으로**(k=2~3) 온다.
  → 주장: "약한 연결의 기능적 중요성은 네트워크 상태에 의존한다. 정지 상태 모델에서 얻은 압축 한계는 실제 뇌에 과대평가된다." **이게 나오면 가장 강한 논문.**
- 예측 B (안 뒤집힘): 절벽 위치가 σ에 무관.
  → 주장: "기능 보존 연결 집합은 상태에 강건하다" — H1 결과가 모델 인공물이 아님을 방어. 덜 극적이지만 필수.
- 어느 쪽이든 결과가 논문에 들어간다.

### H3. 위치 축 — degree-preserving null
- 조작: mag_k와 같은 edge 수·같은 in/out degree 분포, 연결 상대만 무작위 (dp). 별도로 위치는 유지하고 가중치 크기만 섞음 (shuf).
- 예측: dp는 즉사(무작위와 유사), shuf는 부분 보존.
- 해석표:
  | dp | shuf | 결론 |
  |---|---|---|
  | 죽음 | 유지 | 위치가 전부, 크기는 부차 → "wiring diagram의 정보는 topology에 있다" |
  | 죽음 | 죽음 | 위치와 크기 모두 필요 → 압축 시 둘 다 보존해야 |
  | 유지 | — | degree 분포만으로 설명됨 → Dhiman 2026과 일치, 압축은 degree 통계 문제로 환원 (그래도 논문) |

### H4. 과제 축 — 억제·특이성
- 예측: 억제 지수(bitter)와 특이성(groom)이 MN9 비율(sugar)보다 **더 낮은 k에서** 무너진다. 즉 "행동 출력 유지"가 "회로 기능 유지"보다 관대하다.
- 나오면: 압축 평가를 단일 출력으로 하면 안 된다는 방법론적 기여. 압축 곡선을 과제별로 그리는 이유.

### H5. 행동 vs 신경 반응 분리
- 파일럿: k=10에서 MN9 0.86인데 활성 뉴런 385→296, corr 0.87.
- 예측: readout_ratio 곡선과 pearson_union 곡선이 분리되며, 분리 폭이 배경 활동에서 커진다.
- 나오면: "행동은 보존되지만 신경 표현은 이미 바뀐 상태"가 존재 → 뉴로모픽·모델 축약 연구에서 행동만 보는 평가의 위험 지적.

### H6. task-aware가 magnitude를 이기는가
- `act` = |w| × (1 + 원본 모델에서의 전시냅스 뉴런 발화율). 같은 edge 예산.
- 예측: sugar(train)에서는 act ≥ mag, held-out(bitter, jonF)에서는 act ≤ mag (과적합).
- 나오면: task-aware 압축의 전이 한계를 정량화 → 2편째(gradient 기반) 동기.

## 4. 조작 정의

### 4.1 압축 방법 (전부 edge 수를 mag_k에 맞춤)
| 코드 | 정의 | 통제하는 것 |
|---|---|---|
| mag | \|시냅스\| > k인 edge만 | — (주 방법) |
| rand | 같은 수를 무작위 | 크기 정보 |
| dp | mag_k의 edge에서 post 열을 순열 | in/out degree 완전 보존, 위치 파괴 |
| shuf | mag_k의 edge 위치 유지, 크기 순열 (부호는 pre 뉴런 따라 유지 = Dale 법칙) | 크기 파괴, 위치 보존 |
| act | \|w\|·(1+r_pre) 상위 n개 | task-aware |

### 4.2 배경 활동
- `dv/dt = (v_0 − v + g)/τ_m + σ·ξ·τ_m^{−1/2}`, Euler, dt = 0.1 ms
- σ 보정(2026-09-12 실측, 300 ms, 전체 뇌):
  | σ (mV) | 평균 발화율 | 활성 뉴런 비율 | p90 | p99 | max |
  |---|---|---|---|---|---|
  | 1.5 | 0 Hz | 0% | 0 | 0 | 0 |
  | 2.5 | 0.02 Hz | 0.7% | 0 | 0 | 6.7 |
  | **3.5** | **4.3 Hz** | **25.5%** | 6.7 | 77 | 317 |
  역치(7 mV)가 정상 상태 SD(σ/√2)의 2~3배 구간이라 σ 2.5→3.5에서 급격히 켜짐. p99 77 Hz는 fan-in 큰 뉴런의 재귀 증폭 — 논문에서는 "heavy-tailed spontaneous activity"로 보고하고 σ_low도 병행
- 조건: **σ ∈ {0, 3.0 (σ_low), 3.5 (σ_mid)}**. Phase A는 0과 3.5, σ_low는 Phase E

### 4.3 예산 k
k ∈ {1, 2, 3, 5, 10, 20, 31, 50}. 10과 31은 Schlegel 정형성 임계와 일치시키기 위해 고정.

## 6. 통계

- rand/dp/shuf: seed 5 (0–4), trial 5 → 25 관측/조건. mag/act: 결정적이므로 trial 5.
- 각 (task, σ, k)에서 방법 간 차이: seed×trial bootstrap 95% CI (10,000회). p값보다 CI를 보고.
- 절벽 위치 k*: readout_ratio가 0.8 아래로 처음 떨어지는 k를 log-보간. 조건별 k*와 CI를 표로.
- 다중비교: 가설 6개 × 과제 4개 → Holm 보정한 p도 보조로 보고.
- 사전 결정: **어떤 조건도 결과 보고 빼지 않는다.** 이 문서를 논문 supplementary에 첨부.

## 8. 결과 뒤 확장 (1편에 넣을지 2편으로 뺄지 결과 보고 결정)

1. **뉴런 수준 압축**: 원본에서 활성인 뉴런(~400개)만 남긴 부분 그래프 → edge 0.01%. "최소 회로" 추출.
2. **남는 edge의 해부학**: k*에서 살아남은 edge를 super_class·cell_type·뇌영역별로 집계 (flywire_annotations). "무엇이 남는가" = 생물학적 해석 Figure.
3. **Pospisil 선형 모델 고유모드**로 task-aware 점수 개선 (닫힌 형식, CPU 가능).
4. **뉴런 lesion 강건성**: 압축 모델에서 활성 뉴런을 하나씩 침묵 → 원본과 lesion 민감도 비교 (Shiu 논문의 silencing 스크린 재현).

## 10. 통과 가능성에 대한 솔직한 판단

- H2가 뒤집히거나(예측 A), H3에서 dp가 죽고 shuf가 살거나, H4에서 억제가 먼저 무너지면 → **PLOS CB/Network Neuroscience 통과 가능성 높음, Nature Comms 도전 가능.**
- 전부 "그냥 유지된다"로 나오면 → 벤치마크·방법론 논문으로 워크숍 + PLOS ONE급. 그래도 논문.
- 못 내는 경우: 이 설계를 중간에 줄여서 대조군·seed를 빼는 경우뿐.
